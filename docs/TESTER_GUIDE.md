# Memory map — sinovchilar uchun qo‘llanma (v26)

Memory map — qaydlaringiz faqat sizning kompyuteringizda, parol bilan shifrlangan holda saqlanadigan daftar. Serverga hech narsa yuborilmaydi (faqat siz o‘zingiz «Link for everyone» orqali bitta sahifani nashr qilsangiz).

## 1. Ishga tushirish (uch yo‘l)

**A. Tayyor dastur (Python kerak emas).** Windows/macOS/Linux uchun tayyor fayl GitHub Actions orqali quriladi (`.github/workflows/build.yml`, «Run workflow»). Linux dasturi shu yerda tekshirilgan; Windows va macOS dasturlarini men ishga tushirib ko‘rmadim.

**B. Windows:** Python 3.10+ o‘rnating (python.org, «Add python.exe to PATH» belgisi bilan), so‘ng `start.bat` ni ikki marta bosing.

**C. macOS/Linux:** Python 3.10+ bilan `./start.command` yoki `python3 app.py`.

Brauzer o‘zi ochiladi. Birinchi marta parol yaratasiz (12+ belgi).

## 2. Anonim statistika

Birinchi ochilishda Home'da statistika haqida so‘raladi. Rozilik bermasangiz hech narsa yuborilmaydi. Rozi bo‘lsangiz, faqat sonlar yuboriladi (qaysi funksiya ishlatilgani, qaydlar soni oraliq sifatida); qaydlaringiz, sarlavhalar, fayllar va parol hech qachon yuborilmaydi. «See exactly what is sent» bilan aynan nima ketishini ko‘rasiz; Home pastidagi tugma bilan istalgan vaqtda o‘chirasiz.

## 2b. Eng muhim ogohlantirish

**Parolni tiklab bo‘lmaydi.** Unutsangiz, qaydlar ochilmaydi. Parolni xavfsiz joyda saqlang va **Encrypted backup** (··· menyusi) orqali zaxira nusxa oling.

## 3. 10 daqiqalik sinov

1. **Home** sahifasida «Add sample notes» ni bosing.
2. «New note» bilan qayd yarating; ichida `[[boshqa qayd nomi]]` deb yozib ikki qaydni bog‘lang.
3. **3D graph** va **Mind map** ni oching.
4. Qaydga rasm qo‘shing va **Drawing** bilan chizing.
5. Ikkinchi akkauntga ma’lumot jo‘natish: ··· → «Send encrypted ZIP to account…».
6. Bitta qaydni ommaviy qilish: qaydda **Share** → «Publish this note».
7. Telefon va planshetda ham ochib ko‘ring (brauzerda).

## 4. Xato haqida xabar berish

Iltimos quyidagilarni yozing: Memory map versiyasi (Home pastida), operatsion tizim va brauzer, nima qilgansiz, nima bo‘lishini kutgansiz, nima bo‘ldi, imkon bo‘lsa skrinshot. Parol va qayd matnini yubormang.

## 5. Ma’lum cheklovlar

- Real vaqtda birgalikda tahrirlash yo‘q (ataylab: ma’lumot ZIP orqali jo‘natiladi).
- Ommaviy havola (boshqalar uchun) o‘zingiz joylagan server talab qiladi: `docs/HOSTING_V26.md`.
- Ilova faqat brauzer orqali; mobil ilova yo‘q.
- Windows qo‘llovi kodda tayyorlangan, lekin haqiqiy Windows'da sinalmagan.
